# Logo Assets — Donate With Hope Foundation

- `logo-mark-light.svg` — full mark (globe + heart + leaf) for light backgrounds. Navy heart, emerald leaf.
- `logo-mark-dark.svg` — full mark for dark backgrounds (hero, footer). White heart, gold leaf.
- `favicon.svg` — simplified square app-icon version (no globe, for legibility at small sizes). Use directly as a modern SVG favicon, or export to PNG (16/32/180/512px) and `.ico` with a tool like `sharp`, `resvg`, or an online SVG→ICO converter for full legacy browser support.

All marks are built on a 200×200 viewBox (favicon on 64×64) so they scale cleanly at any size. Colors reference the brand tokens: Navy `#0B3D91`, Emerald `#2E8B57`, Gold `#F4B400`, White `#FFFFFF`.
